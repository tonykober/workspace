Depth Studio 技術調研報告

調研日期：2026-08-04 ｜ 調研者：研究員

專案概要

Depth Studio 是由 Prompt Case 團隊開發的開源工具，將普通影片轉換為時序一致的灰階深度影片，作為 AI 影片生成的空間引導（Spatial Guide）。

GitHub：github.com/Toolsai/Depth-Studio

授權：MIT（整合程式碼）+ Apache 2.0（底層模型）

星數：10（2026 年新專案，剛起步）

平台：Windows 10/11macOS 14+ (Apple Silicon)

定位：深度前處理工具 — 產出深度影片供下游 AI 影片工具使用

技術特色一覽

  • 本地處理：影片不上傳雲端，隱私安全
  • 一鍵安裝：提供 .bat（Windows）/ .command（macOS）啟動器
  • AI Agent 友善：提供 SKILL.md，可讓 AI agent 自動安裝啟動
  • 支援 npx：npx skills add Toolsai/Depth-Studio
  • 首次執行自動下載模型（~116 MB），不需 Hugging Face 帳號
  • 時序穩定：統一亮度範圍，避免幀間閃爍

核心技術

底層使用 ByteDance 的 Video-Depth-Anything-Small 模型，該模型為 CVPR 2025 Highlight 論文成果。

項目規格
模型架構基於 Depth Anything V2（ViT-Small）
參數量28.4M（輕量）
推理延遲7.5ms/frame（FP16, A100）
顯存需求6.8 GB（FP16）
模型大小~116 MB
論文arXiv:2501.12375

相比 diffusion-based 深度估計方案，Video-Depth-Anything 的優勢是速度更快、參數更少、時序一致性更好。

運作流程

1
上傳影片
使用者透過本地 Web 介面選擇參考影片

範例：C01-001 曜天火 天火尊者 法術A 抽卡動畫

2
深度估計
Video-Depth-Anything-Small 模型逐幀估計相對深度（近處明亮、遠處暗沉）
3
全域正規化
整支影片使用統一的亮度範圍，避免逐幀閃爍，保持時序穩定
4
輸出結果
產出灰階 MP4，保留原始解析度、FPS、幀數和時長

範例輸出：C01-001 曜天火 深度影片結果

5
預覽下載
原片與深度影片並排比較，可選反轉深度方向或分段下載

技術細節

  • 預設輸出：近白遠黑
  • 可選 Invert depth：反轉為近黑遠白（依下游工具需求）
  • Split 功能：可將長影片分段輸出為 ZIP
  • 處理完畢後臨時檔案自動清除

應用場景

產出的深度影片可搭配支援 depth-guided 的 AI 影片工具：

  • 角色替換 — 替換影片中的人物為另一角色
  • 動作遷移 — 保持原始動作/姿態生成新角色
  • 空間引導 — 為 AI 生成器提供比純文字更強的距離/位置資訊
  • 場景保持 — 保持場景距離感和身體動態

⚠️ 重要提醒：本工具只產深度圖，不做最終角色生成。深度支援取決於你使用的下游 AI 影片工具或模型。

深度圖 vs 普通參考影片的差異

普通參考影片深度引導影片
顯示色彩和外觀顯示距離資訊（近/遠）
AI 可能被外觀干擾AI 專注於空間結構
動作引導較弱姿態/輪廓引導更明確

評估分析

✅ 優勢

  • 輕量、快速、本地運行
  • 時序穩定不閃爍
  • 安裝門檻低（一鍵啟動）
  • 開源可審計
  • Small 模型可商用（Apache 2.0）
  • 不需 GPU 也能跑
  • 不依賴雲端服務

⚠️ 限制

  • Small 模型精度不如 Large
  • 僅估計「相對深度」（非絕對距離）
  • 深度結果品質取決於下游工具支援度
  • 專案剛起步（3 commits, 10 stars）
  • 長影片記憶體需求較高
  • 社群教學/使用心得幾乎為零
  • Base/Large 不可商用

總結

Depth Studio 是一個定位清晰的「深度前處理工具」，把 CVPR 2025 的 Video-Depth-Anything 模型包裝成易用的本地 Web 介面。適合需要從真人動作影片提取深度引導、再交給 AI 影片模型做角色替換或動作遷移的創作流程。

技術基礎紮實但專案本身很新，適合早期嘗鮮。目前網路上幾乎沒有使用心得或完整教學，需要自行摸索搭配下游工具的最佳實踐。

實際測試流程建議

安裝方式

git clone https://github.com/Toolsai/Depth-Studio.git
cd Depth-Studio
# Windows: 雙擊 install-and-launch.bat
# macOS: 雙擊 install-and-launch.command

使用步驟

  1. 點 Browse 選影片（建議 5-15 秒、有明顯動作和景深差異）
  2. Split 設 0（完整輸出）
  3. Invert depth 先不勾（預設近白遠黑）
  4. 點 Generate depth，等進度條跑完
  5. 比較原片與深度影片，確認品質後下載

搭配下游工具的三條路線

路線工具難度做法
A可灵 (Kling)⭐ 低上傳深度影片作為結構引導
BRunway / Pika⭐ 低上傳作為 structure reference
CComfyUI + ControlNet⭐⭐⭐ 高逐幀送入 depth ControlNet 通道

測試時記錄重點

  • 動作跟隨度（姿態是否保留）
  • 時序一致性（有無閃爍/跳動）
  • 深度引導強度是否需調整
  • Invert depth 開/關的差異

預期結果

  • 有明顯前後景深、大動作的片段效果最好
  • 靜態或動作很小的片段，深度引導優勢不明顯
  • 不同下游工具對 depth 的解讀方式可能不同，需試 invert 開/關
