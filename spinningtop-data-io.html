SpinningTop 工具/編輯器 資料讀寫方式盤點

日期：2026-07-27 ｜ 目的：了解各工具目前的資料讀寫架構，作為 main 分支修改的參考

雲端 KV API 資訊

  • API: https://spinningtop-files-api.tonykober.workers.dev/api/files
  • Auth: Bearer spinningtop-dev-2026
  • 操作：GET/PUT/DELETE /api/files/{path}
  • 列表：GET /api/files?prefix={prefix}

各工具讀寫方式現狀

VFX Editor（tools/vfx-editor/）

功能讀取來源儲存目標離線可用？
特效 preset雲端 KV vfx-presets/雲端 KV❌
組合特效雲端 KV vfx-composites/雲端 KV❌
觸發設定雲端 KV vfx-triggers/config.json雲端 KV❌
遊戲格式匯出—雲端 KV game-effects/❌
素材包 sprite sheet本地 public/flipbooks/—✅
自訂上傳 spritelocalStorage + 雲端 KV sprite-sheets/localStorage + 雲端 KV⚠️ 部分
內建 preset（程式碼）VFXSystem.ts 硬編碼—✅

相關檔案：

  • src/PresetLibrary.ts — preset 的 CRUD
  • src/TriggerManager.ts — 觸發設定的 CRUD
  • src/CompositeEffect.ts — 組合特效的 CRUD
  • src/SpriteSheetUploader.ts — 自訂素材上傳
  • src/main.ts — 匯出遊戲格式、角色模型載入

功能讀取來源儲存目標離線可用？

  • src/cloudStorage.ts — 雲端開啟/儲存

功能讀取來源儲存目標離線可用？

  • Script/System/RenderSystem/Adapters/EffectAdapter.ts — loadCustomEffects / loadCompositeEffects / loadTriggers
