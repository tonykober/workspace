🎯 推薦搭配策略

三層架構

【動作來源層】快速生成原始動作 Kimodo（文字→3D）+ WHAM（影片→3D）+ DWPose（圖片→姿勢） ↓ 【精修/分支層】品質提升與格式轉換 Cascadeur（3D精修）+ ControlNet（2D姿勢控制）+ Flux（精準姿勢圖） ↓ 【產線輸出層】遊戲資產產出 BVH/FBX（3D動作）+ Spine（2D骨骼動畫）+ SD批量渲染（Sprite Sheet）

分層策略

層級核心工具原則
動作來源Kimodo + WHAM速度優先 — 快速取得 80% 品質素材
精修分支Cascadeur + ControlNet正確性優先 — 修正物理/姿勢問題
產線輸出Spine + SD 工作流穩定性優先 — 確保格式正確可整合

建議優先建設順序

  1. 立即可用（已有）：Kimodo + DWPose + ControlNet → 文字生成 3D 動作 + 姿勢控制 2D 圖
  2. 短期建設：加入 WHAM（影片萃取）+ Cascadeur（動作精修）
  3. 中期產線：建立 SD 批量渲染 Sprite Sheet 工作流 + Spine 動畫產線
  4. 持續追蹤：MoMask（編輯能力）、Scenario.com（風格一致性）、Flux API（姿勢精度）
結論：Kimodo 是 3D 動作量產核心（已部署），搭配 DWPose + ControlNet 延伸到 2D 姿勢控制。商業工具中 Cascadeur 性價比最高（免費版即可精修）。2D 遊戲動畫以 Spine 為產線標準，AI 輔助生成 Sprite Sheet 用 SD + ControlNet 工作流最靈活。
