🔬 See-through — 圖層拆解 AI

SIGGRAPH 2026PythonCUDA

功能

  • 單張動漫圖 → 最多 23 個語義圖層（頭髮/面部/眼睛/衣物/手/飾品）
  • 全自動 背景補洞（被遮擋區域自動修補）
  • 自動推導 繪製順序（drawing order）
  • 輸出：PSD + depth map + segmentation mask

技術棧

元件用途模型 ID
LayerDiff 3D透明分層 + 補洞layerdifforg/seethroughv0.0.2_layerdiff3d
MarigoldPseudo-depth estimationlayerdifforg/seethroughv0.0.1_marigold
SAM body parsing語義身體分割24yearsold/l2d_sam_iter2

硬體需求（VRAM）

推理模式VRAM備註
bf16, 1280px12–16 GB標準模式
--group_offload~10 GB慢 1.5x
NF4 quantized~8 GB量化推理
block swap~8 GB分塊交換

執行指令

python inference/scripts/inference_psd.py \
  --srcp assets/test_image.png \
  --save_to_psd

# 輸出: workspace/layerdiff_output/

環境需求

  • Python 3.12 + PyTorch 2.8.0 + CUDA 12.8
  • Conda 虛擬環境
  • 處理時間：每張約 2-3 分鐘（官方自述）
Marigold 模型 ID 問題：原始 repo 指向 24yearsold/seethroughv0.0.1_marigold 會 404。需改用 layerdifforg/seethroughv0.0.1_marigold。

🎮 Anime2.5DRig — 瀏覽器 2.5D 綁定

WebGLJavaScript規則式

功能

  • 分層 PSD → 瀏覽器 WebGL 可互動操控的 2.5D 角色
  • Webcam 面部追蹤（MediaPipe）
  • 麥克風嘴型同步
  • 頭髮/胸部 彈簧物理
  • 虹膜 stencil 限制（在眼白範圍內活動）
  • 透明/綠幕背景

技術實現（rigger.js）

機制說明
SLOTS 對照表定義各圖層深度/分組/淡入淡出/物理效果
面部定位以 face 層中心為錨點，用重心計算分離左右眼/眉
髮絲識別輪廓掃描 + 峰值檢測，單層最多 6 條
眼睛/嘴動作開閉圖層間的 crossfade
物理模擬簡化 spring 系統（頭髮/胸部）
渲染WebGL1 mesh warp + stencil render
追蹤MediaPipe CDN（僅 webcam 啟用時載入）

PSD 規範

  • 扁平化圖層（不能用資料夾/群組）
  • face 圖層為必要定位錨點
  • 命名嚴格遵循工具定義規則
  • 建議正方形畫布 768×768 ~ 2048×2048

運行方式

# 本地預覽（無需 npm）
python -m http.server 8000

# webcam/mic 需 HTTPS 或 localhost
# file:// 僅支援 PSD drop 預覽

⚠️ 整合注意事項

neck / topwear 前後遮擋關係常出錯。若直接用 See-through 輸出，需手動將 neck 合併至 topwear。

See-through 不包含的後續工作
