🔴 看這份之前要先知道一件事：程式裡有兩條渲染路徑，實際出貨的只有一條。
正式版跑的是 compat 模式，另一條純 2D 的舊路徑只在開發版存在（正式版刻意不留退路）。 本盤點全部以正式版實際會跑的 compat 為準；很多檔案在舊路徑下畫很多東西，但正式版根本不執行。

畫面是五層疊起來的

不是一張 canvas 疊 3D，而是五層交錯。兩張 2D canvas 中間夾著 HTML 的介面層，這是理解整個渲染的關鍵。

30獎勵演出WebGL：報獎大卡、裝備取得
20前景 canvas2D：要蓋過介面的東西（噴票、倒數、教學泡泡）
10介面層HTML DOM：玩家面板、彩票數、任務格
5遊戲 canvas2D：場地裝飾、預警、提示、特效
03D 場景WebGL：陀螺本體、怪物、地板特效

結論：canvas 現在主要負責「資訊」不是「角色」
  • 陀螺本體、怪物本體都已經在 3D。要改它們的外觀，改這 25 個檔沒有用，要去 WebGL 那邊。
  • canvas 剩下的是：攻擊預警、鎖定提示、蓄力弧條、票值數字、報獎演出、教學泡泡、換場字幕。
  • 所有發光效果都為了效能被拿掉了。現在畫面上的霓虹感是用雙層描邊假裝的，不是真的光暈。
  • 特效的 JSON 檔在正式版沒被使用。特效試辦開關預設關閉，玩家看到的是寫死在程式裡的版本，改 JSON 不會有反應。但報獎、超級衝撞、票值那幾個介面用的 JSON 是活的。

🔴 21 項確認的死碼

這些程式碼還在，但玩家永遠看不到。分三類：

① 條件被寫死為永不成立（8 項）

  • 膠囊場地邊框 —— 函式開頭無條件返回
  • Boss 纏鬥中央大字、半球護盾罩、P 位色呼吸光環、「請投幣」文字
  • 水泥塊耐久條、炸藥桶耐久條
  • 報獎項目的外層縮放 —— 另一個變數恆為真，使這段永遠跳過

② 整段被註解掉（3 項）

  • 四邊藍色鋼鐵尖刺（128 行）
  • 碰撞邊界虛線 —— 標記「緊急隱藏 2026-08-20」
  • 子彈陀螺拖尾（132 行）

③ 資料來源永遠沒有內容（5 項）

  • 子彈陀螺 —— 全專案零筆寫入
  • 分身幻影 —— 只有清空與過濾
  • 星星箱 —— 生成函式停用
  • Boss 中央星爆 —— 註解自稱已退役
  • 刀刃損毀爆散 —— 美術做了 JSON 但沒接上

④ 沒有任何地方呼叫的函式（5 組）

  • 教學泡泡的完整版（現在只用純文字版）
  • 四個怪物預警繪製 —— 2026-09-10 起改由 3D 著色器畫，原程式刻意保留當作改動前的外觀對照
  • 連擊刀刃環、幾個工具函式與兩個匯入後沒用到的資產
刪除前建議確認：第 ④ 類有些是刻意保留當對照用的，程式註解有寫。第 ③ 類的刀刃損毀是美術資產已存在但沒接線，可能是想做而沒做完，不一定要刪。
