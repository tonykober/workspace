Animation Editor 使用手冊

SpinningTop 角色動畫編輯器 — 用於設定遊戲角色的 FBX 模型、動畫區段、狀態機、Toon 材質參數，並匯出 .anim.json 供遊戲端 ZombieModelLoader 讀取。

線上版：https://spinningtop-daichi.pages.dev/editor/animation/

介面說明

┌─────────────── Header（工具列）──────────────────┐
│ 🎬動畫編輯器 │ 載入FBX │ 載入外部動畫 │ 載入貼圖 │
│ 匯出JSON │ 匯入JSON │ ☁雲端開啟 │ ☁雲端儲存 │
├──────────┬──────────────────────┬────────────────┤
│ 左欄      │ 中央 3D Viewport     │ 右欄            │

│           │  ┌光源指示器(右上)┐   │                 │

│ State 列表 │  └───────────────┘   │ （Clip/State/   │
│ Mesh 貼圖  │                      │  Behavior）     │
├──────────┴──────────────────────┴────────────────┤
│ Timeline（時間軸，高 200px）                        │

各區域功能

  • 左欄：管理 Clips（動畫區段）、States（狀態機）、Mesh 貼圖列表

3.2 Flipbook Sprite Sheet 動畫系統

原理：自訂 ShaderMaterial 中，fragment shader 根據每個粒子的 age / maxLifetime 計算當前幀編號，再將 gl_PointCoord 映射到 sprite sheet 中該幀的 UV 區域。

Shader 公式：

float frame = floor(lifeProgress * totalFrames);
float col = mod(frame, cols);
float row = floor(frame / cols);
vec2 cellSize = vec2(1.0 / cols, 1.0 / rows);
vec2 uv = vec2(col, row) * cellSize + gl_PointCoord * cellSize;

設定方式：

  1. 渲染模式選「Flipbook 動畫」
  2. 貼圖選任一 🎬（程序化）或 📦（素材包）sprite sheet
  3. 下方自動出現 Flipbook 設定：
    • 行數（flipbookRows）：sprite sheet 行數
    • 列數（flipbookCols）：sprite sheet 列數
    • 循環（checkbox）：勾選 = 循環播放，不勾 = 播完停在最後幀
  4. 選擇 📦 素材包貼圖時，自動帶入正確的 rows/cols（無需手動設定）

預設行為：原地播放

  • 所有內建 Flipbook preset 預設 speed=0, gravity=0（原地播放序列圖）
  • 序列圖本身已包含動畫效果（形狀變化/淡出等），不需要額外粒子運動
  • 如需輔助運動（如煙霧向上飄），可手動調整速度/重力/方向等運動參數
  • 所有運動參數面板保留顯示，不隱藏
  • 也可搭配 Continuous 發射模式（每幀逐顆產生 flipbook 粒子）

3.10 發射模式（Burst / Continuous）

模式說明適用場景
Burst（爆發）一次性噴出所有粒子爆炸、打擊、斬擊
Continuous（持續）每幀逐顆激活粒子，場上同時有不同年齡的粒子煙霧、火焰、噴泉、護盾

Burst 模式

  • 按「▶ 預覽」→ 一次噴出 count 顆粒子
  • 粒子消失後效果結束
  • 有效欄位：數量（count）
  • 灰色禁用：發射率、時長（hover tooltip 說明原因）

Continuous 模式（Ring Buffer 粒子池）

  • 按「▶ 預覽」→ 啟動持續特效
  • 每幀根據 emissionRate 逐顆激活新粒子
  • 死亡粒子自動回收再利用（ring buffer，零記憶體分配）
  • 場上同時有剛出生的 + 快消失的 = 視覺連續不間斷
  • duration 結束後停止發射，等最後一批粒子消失後自動移除
  • 有效欄位：發射率（rate）、時長（duration）
  • 灰色禁用：數量（自動計算 = 發射率 × 壽命 × 1.3，顯示在欄位中）
  • 效能：200 顆以下無影響

欄位互斥行為

切換模式時，無效欄位自動灰色（opacity 0.4 + 不可點擊），tooltip 說明原因：

  • Burst 下的發射率：「⚠️ 爆發模式下無效 — 切換為持續發射才需要」
  • Continuous 下的數量：「⚠️ 持續模式下自動計算（= 發射率 × 壽命 × 1.3）」

3.14 組合特效（Composite Effect）

概念：一個組合特效 = 多個子特效層，各層可設延遲觸發、位移偏移、旋轉、縮放，組合播放形成完整的多層卡通特效。

父子層概念：

  • 組合 = 父層（紅色箭頭，spawnHelper 控制整體位置）
  • 各圖層 = 子層（藍色箭頭，layerHelper 控制相對偏移）
  • 父層移動 → 所有子層跟著移動
  • 子層拖動 → 只改那層的相對 offset

介面：

  • 左側列表「🎭 組合特效」分類
  • 右側面板頂部顯示圖層列表（composite-header）
  • 選中組合名稱 = 組合層級設定
  • 選中某圖層 = 該層參數面板（完整 ParticleConfig 可調整）

3 個內建組合：

名稱層構成
🎭 打擊命中閃光 + 火花(bolt stretched) + 衝擊環(flipbook_impact)
🎭 死亡爆炸閃光 + 爆炸雲(sheet_explosion) + 碎片飛散(diamond) + 煙霧(flipbook_smoke)
🎭 斬擊完整SVG 十字斬 + 火花(spark stretched) + 衝擊線(sheet_hyperspeed)

雲端存取：KV 路徑 vfx-composites/{name}.json

CompositeLayer 欄位：

欄位說明
name圖層名稱
preset完整 ParticleConfig
delay延遲觸發（秒），0=同時
offsetX/Y/Z相對位移（父子層概念）
rotationX/Y/Z旋轉（度數）
scale縮放倍率
visible👁 顯隱（預覽時可單獨關閉）

操作步驟：

  1. 點左側「🎭 組合特效」任一項，或底部「＋ 新增組合特效」
  2. 右側面板頂部顯示：組合名稱（可點選 = 組合層級）+ 各圖層行
  3. 組合層級：點組合名稱 → 顯示改名/新增圖層/儲存/另存/🗑️刪除
  4. 圖層層級：點某圖層 → 下方展開延遲/縮放設定 + 完整特效參數面板
  5. 新增圖層：彈出 modal → 空白/從現有 preset 載入/從組合載入全部層
  6. 三軸控制：W=移動 offset / E=旋轉 / R=縮放（藍色箭頭指示位置）
  7. 儲存：組合層級 = 存整個組合 / 圖層層級 = 存為獨立 preset
  8. 預覽：▶ 預覽按鈕觸發所有可見層（按各自 delay 依序觸發）

保存提示：

  • 修改後組合名稱顯示 * 號（如「打擊命中 *」）
  • 切換到其他特效時彈出 modal：💾 保存 / 📋 另存 / 🗑️ 放棄 / ← 取消
  • 同一組合內切換圖層不彈確認（自動保留修改）

3.15 Flipbook 起始/結束幀

Flipbook 設定中新增「起始幀」和「結束幀」：

  • 起始幀：從第幾幀開始播放（預設 0 = 第一幀）
  • 結束幀：播到第幾幀停止（預設 0 = 播到最後一幀）
  • 用途：多色 sprite sheet 只播某一色段（如 Alt Slash 的紫色段 = 幀 0~7）
  • Shader 計算：frameRange = endFrame - startFrame + 1，frame = startFrame + floor(progress × frameRange)

4. 使用步驟

4.1 製作一個靜態粒子特效

  1. 左側「＋ 新增特效」或選取現有 preset 修改
  2. 右側面板調整：粒子數 / 速度 / 大小 / 壽命 / 顏色（起始→結束漸變）/ 散射角度+方向 / 重力 / 透明度
  3. 外觀區選擇貼圖形狀（如 ⚡ bolt）
  4. 選擇渲染模式（billboard / stretched / trail）
  5. 按「▶ 預覽」查看效果
  6. 按「🔁 循環」持續重播（特效結束後 ~300ms 自動重播）
  7. 滿意後按「💾 儲存」或「📋 另存新檔」

4.2 製作一個 Flipbook 動畫特效

  1. 外觀區「渲染」選「Flipbook 動畫」
  2. 「貼圖」下拉選 📦 素材包（如 💥 Explosion）或 🎬 程序化動畫
  3. Flipbook 設定自動出現：行列數自動帶入，或手動調整
  4. 勾選「循環」可讓動畫重複播放（適合持續型特效如火焰/護盾）
  5. 調整粒子數量（少量大顆粒效果更好）、壽命（配合動畫時長）
  6. 「▶ 預覽」確認動畫播放
  7. 調整顏色（白底素材會被粒子顏色著色）

4.3 製作 SVG 手繪斬擊特效

  1. 外觀區「渲染」選「SVG 動畫」
  2. SVG 設定面板出現
  3. 選擇類型：弧形斬 / 十字斬 / 旋轉斬
  4. 調整參數：弧度、線寬、描邊速度
  5. 設定發光層數（越多越亮）和手繪度（越高邊緣越粗糙）
  6. 「▶ 預覽」查看 — 每次播放邊緣都略有不同（Rough.js 隨機性）
  7. 顏色欄位：color = 中心色，colorEnd = 發光色

4.4 上傳自訂 Sprite Sheet

  1. 準備 PNG sprite sheet（NxN grid，建議 ≤ 512px）
  2. 拖放到 Viewport 或點「📤 上傳 Sprite Sheet」
  3. 設定彈窗中：命名、選擇行×列格式（快速選或自訂）
  4. 確認 → 自動加入下拉選單「📷 自訂素材」分組
  5. 渲染模式自動切換為 Flipbook + 帶入行列數

4.5 匯出到遊戲

  1. 按「📤 匯出遊戲格式」
  2. 選擇「確定 = 存到雲端」或「取消 = 下載本地」
  3. 自動推斷特效類型（shockwave/slash/explosion/hit）
  4. 遊戲端 EffectAdapter 啟動時自動從 game-effects/ 讀取

4.6 設定遊戲特效觸發

  1. 點頂部「⚡ 觸發設定」進入觸發管理模式
  2. 「＋ 新增規則」建立新觸發規則
  3. 選擇事件類型（命中/擊殺/爆炸等）
  4. 選擇目標特效（下拉選中文名稱）或組合特效
  5. 設定機率（0~1）、冷卻（秒）、併發上限
  6. 設定 PlaySettings（尺寸/延遲/旋轉/偏移/縮放的隨機範圍）
  7. 「▶ 預覽」確認效果（可勾循環持續觀看）
  8. 「💾 保存此規則」寫入 KV
  9. 遊戲重新整理 → 新規則自動生效
